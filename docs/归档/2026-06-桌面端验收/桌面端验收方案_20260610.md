### Task 5: Stylelint手动修复

**预计时间**: 1小时

#### 5.1 关键问题修复

| 问题类型 | 数量 | 修复方法 |
|---------|------|---------|
| property-no-unknown | ~30 | 添加stylelint配置支持CSS变量 |
| max-nesting-depth | ~15 | 重构嵌套结构 |
| scss/no-global-function-names | ~8 | darken()→color.adjust() |

#### 5.2 配置优化

在 `.stylelintrc.js` 中添加CSS自定义属性支持:

```javascript
rules: {
  'property-no-unknown': [
    true,
    { ignoreProperties: ['stemPrimary', 'stemSecondary', '--*'] }
  ]
}
```
