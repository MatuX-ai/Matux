# 学习端用户菜单功能测试规范 v1.0

## 一、测试概述

用户菜单位于学习端顶部导航栏右侧，点击用户名/头像展开下拉菜单，提供用户相关操作入口。

### 1.1 菜单结构

| 序号 | 功能名称 | 路由/Action | 图标 |
|------|----------|-------------|------|
| 1 | 个人资料 | `/user/profile` | person |
| 2 | Token管理 | `/user/token` | token |
| 3 | 成就系统 | `/user/achievements` | emoji_events |
| 4 | AI教师设置 | `/user/ai-teacher-settings` | smart_toy |
| 5 | 退出登录 | `logout()` | logout |

---

## 二、通用测试步骤（每模块均需执行）

| 步骤 | 检查项 | 验收标准 |
|------|--------|----------|
| **S1** | 编译验证 | `ng build` 无 TS 错误，0 error, 0 warning |
| **S2** | 路由可达 | 导航到模块 URL，页面加载无白屏、无 console error |
| **S3** | 功能完整性 | 逐功能点验证（CRUD、API 交互、状态变更），所有功能点与 PRD 一致 |
| **S4** | 边界与异常 | 空数据、网络断开、非法输入、并发操作，优雅降级，无未捕获异常 |
| **S5** | UI 响应式 | 1024x768 / 1920x1080 / 缩放 125%，布局不错乱、文字不溢出 |

**每步发现问题 → 定位 → 修复 → 回归验证 → 继续下一步**
