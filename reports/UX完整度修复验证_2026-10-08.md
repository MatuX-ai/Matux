### P0-B 状态栏 pairwise 竞态

**问题根因**:
原代码使用 `pairwise() + filter(prev !== curr)`，当 StatusBar 在后订阅时 BehaviorSubject 已发出 `true`，pairwise 缓冲 `[true]`，后续健康检查仍为 `true` 时 filter 拦截，状态栏永远停留在「后端检测中…」。

**修复后**:
```typescript
this.moduleStatusService.healthy$
  .pipe(
    startWith(this.moduleStatusService.healthy$.value),  // 立即发射当前值
    distinctUntilChanged(),                              // 仅发射变化
    map((healthy) => healthy ? 'healthy' : 'unhealthy'),
    takeUntil(this.destroy$)
  )
  .subscribe((status) => {
    this.backendStatus = status;
  });
```

并增加主动触发：
```typescript
this.moduleStatusService.fetchHealth();
```

**验证**:
- `/health` 端点 → HTTP 200
- `/api/v1/system/health-detail` 端点 → HTTP 200
- StatusBar 现在应在 3 秒内从「检测中」跳到「运行中」
