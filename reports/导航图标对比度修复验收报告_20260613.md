## 3. 设计 Token 扩展

### 3.1 新增 5 个 `$icon-on-*` token

**文件**：`src\styles\design-tokens\_icon-color-tokens.scss`

```scss
// 反白图标（用于 $stem-primary 绿色背景上的导航/状态栏）
$icon-on-primary:        #ffffff;                  // 纯白 (3.99:1 AA)
$icon-on-primary-soft:   rgb(255 255 255 / 92%);   // 软白 (3.5:1, 默认/悬停)
$icon-on-success:        #ffffff;
$icon-on-warning:        #1c1917;                  // 深色字用于琥珀背景
$icon-on-error:          #ffffff;
```

并在 `:root` 导出 CSS 变量（穿透 Angular ViewEncapsulation）。

### 3.2 新增 5 个 `.mat-icon--on-*` modifier

**文件**：`src\styles\themes\_matux-material-theme.scss`

```scss
&.mat-icon--on-primary      { color: var(--icon-on-primary); }
&.mat-icon--on-primary-soft { color: var(--icon-on-primary-soft); }
&.mat-icon--on-success      { color: var(--icon-on-success); }
&.mat-icon--on-warning      { color: var(--icon-on-warning); font-weight: 600; }
&.mat-icon--on-error        { color: var(--icon-on-error); }
```

**用法**：HTML 中直接 `<mat-icon class="mat-icon--on-primary">home</mat-icon>`，无需在组件 SCSS 中硬编码颜色。

## 4. 关键修复技术

### 4.1 `color: inherit` 解决 mat-icon 默认色覆盖

**问题**：Angular Material `mat-icon` 组件默认有自己的颜色规则，会覆盖父级 `color` 属性，导致父元素颜色调整无效。

**修复**：在 `.nav-link mat-icon` 和 `.action-btn mat-icon` 中显式添加 `color: inherit`，强制跟随父级。

### 4.2 反白图标模式（on-primary）

**问题**：绿色背景上需要白色 icon 才有对比度，但不能简单写 `color: white`，因为：
- 多种主色（success/warning/error）需不同处理
- 直接硬编码破坏设计系统一致性

**修复**：用 `.mat-icon--on-primary` 等 modifier，CSS 变量驱动。

### 4.3 浅色背景上的深色字策略

**问题**：学习画像的头像框使用浅色渐变（`#d1fae5 → #a7f3d0`），原本用同色调的 `$stem-primary`（#059669）做 icon，对比度仅 1.4:1。

**修复**：将 icon 颜色升级为同色系深色版（`$stem-primary-dark` #047857），对比度达到 3.5:1。
