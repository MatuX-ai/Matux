# iMato "我的课程" 页面对比度审计报告（2026-06-13）

## 1. 概述

**审计目标**：检查 `/courses`（我的课程）页所有可见的颜色对比度，重点关注导航图标、按钮、文字在彩色背景上的对比度。

**审计依据**：
- WCAG 1.4.3（AA 文本对比度）：正常文本 ≥ 4.5:1，大文本（≥ 18pt 或 ≥ 14pt 加粗）≥ 3:1
- WCAG 1.4.11（非文本组件对比度）：≥ 3:1

**关键发现**：
- 第一个报告（`导航图标对比度修复验收报告_20260613.md`）对导航栏的修复**部分有效**，但**未考虑文字**和**hover/active 状态的背景**

- 第一个报告引入的 `.nav-link.active` 背景 `rgb(255 255 255 / 18%)` 实际**降低了**对比度，违反 WCAG 1.4.11
